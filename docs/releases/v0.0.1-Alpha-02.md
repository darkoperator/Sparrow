# Sparrow v0.0.1-Alpha-02

Third test build, for a small group. Expect rough edges, and check anything that matters against the original evidence before relying on it.

Sparrow turns Microsoft 365 evidence for a business-email-compromise investigation into one queryable DuckDB case file. It reads Hawk 3.x/4.x, Microsoft-Extractor-Suite (Invictus) and portal exports, then gives you a CLI and a desktop review app to work the case. It does not collect evidence itself. Use it only on collector output you are authorized to examine.

## What's new

- **Large files import.** Files are read from disk as they load, instead of being held in memory whole, so there is no longer a 1 GiB file limit. `--max-file-size BYTES` still sets a limit if you want one. XLSX workbooks stay limited to 1 GiB. On 3 GB portal exports, a message trace imports at a 5 GB peak (was 17.8 GB) and an Entra audit at 4.2 GB (was 18.6 GB).
- **A large portal Entra audit case profiles.** Profiling a case with a multi-gigabyte Entra audit export used to run out of memory. It now finishes.
- **Progress inside a file.** Import shows each file's step and how far through it is, and Cancel takes effect mid-file. A step that cannot measure its progress shows a moving bar with its record count.
- **Lower memory use by default.** DuckDB is capped at 2 GB (was 4 GB). `SPARROW_MEMORY_LIMIT=4GB` is somewhat faster on a big case if you have the memory.
- **Faster raw-text search in Events.**
- **Tenant grouping.** A collection with no tenant id or name, such as a portal Entra audit CSV without `ActorHomeTenantId`, joins the tenant that owns its users' domains.
- **A Windows Hello key change** is listed under the device whose key came or went.
- **Quitting the app** no longer waits on a CLI that stopped responding.
- **Detection rule reference.** Every built-in rule is described in [Detection rules](https://github.com/darkoperator/Sparrow/blob/v0.0.1-Alpha-02/docs/RULES.md).
- **Record size limit.** A single CSV or JSON record over 64 MiB fails the rest of that file, with a message that says so, instead of being held in memory.

## Install

Download the app and the CLI from this release. Install both from the same release: they refuse to talk to each other across versions, so the CLI from `v0.0.1-Alpha-01` will not work with this app.

The builds are not code-signed or notarized, so your system will warn you. `SHA256SUMS-macos-arm64.txt` lets you check each download first.

### macOS (Apple silicon)

1. Unzip `Sparrow-0.0.1-Alpha-02-macos-arm64.zip` and move `Sparrow.app` to Applications. If macOS blocks it the first time you open it, go to **System Settings > Privacy & Security** and choose **Open Anyway**. If it says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Sparrow.app`.
2. Run `tar -xzf sparrow-cli-0.0.1-Alpha-02-macos-arm64.tar.gz` and put `sparrow` in a folder on your `PATH`.

To check a download, run `shasum -a 256 -c SHA256SUMS-macos-arm64.txt` in the download folder.

### Windows, Linux and Intel Macs

No build is attached yet. Build from source with `scripts/release.sh`; see [Developer notes](https://github.com/darkoperator/Sparrow/blob/v0.0.1-Alpha-02/docs/DEVELOPING.md). The Windows installer on `v0.0.1-Alpha` still works, but it does not have these changes.

## Try it

Without any real evidence, Sparrow can generate a synthetic case:

```
sparrow synth --scenario bec-aitm --collector hawk4 --out tree
sparrow ingest tree --case case.duckdb
sparrow capabilities --case case.duckdb
sparrow finding list --case case.duckdb
```

Then open `case.duckdb` in the app. To use your own evidence, point `sparrow ingest` at a collector folder, or build a new case from a folder in the app.

GeoIP is optional. Without MaxMind GeoLite2 City and ASN files, passed with `--geoip-dir DIR`, there is no geolocation, and rules that need it report `not_applicable`.

## Known limits

- There is no automatic update. Each new build is a manual install of both the app and the CLI.
- Case files from this build may not open in later alpha builds, so keep your original evidence and expect to re-ingest.
- Only one process can write to a case file at a time.
- MailItemsAccessed exports are still read whole, so a very large one needs memory to match.
- In Events, a column the backend cannot filter or sort, such as Target, still cannot be. Use the raw-text search.
- The Access CSV has no app name column; its `app` column holds the application id or client text.
