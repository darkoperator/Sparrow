# Sparrow v0.0.1-Alpha-03

Fourth test build, for a small group. Expect rough edges, and check anything that matters against the original evidence before relying on it.

Sparrow turns Microsoft 365 evidence for a business-email-compromise investigation into one queryable DuckDB case file. It reads Hawk 3.x/4.x, Microsoft-Extractor-Suite (Invictus) and portal exports, then gives you a CLI and a desktop review app to work the case. It does not collect evidence itself. Use it only on collector output you are authorized to examine.

## What's new

- **Country and ASN in the app.** Cases built or re-profiled in the app had no country or ASN on any IP address, because the app never passed the MaxMind databases to the profile step. The import dialog now has a **GeoIP (country and ASN)** line. **Change…** picks the folder holding the GeoLite2 City and ASN `.mmdb` files; without a choice, the app uses `~/geoip` when it holds both. If no databases are found, or the chosen folder is missing (an unplugged drive, say), the import result says so, and addresses profiled earlier keep their values.
- **Fixing a case built with an earlier build:** close the case in the app and run `sparrow profile --case case.duckdb --geoip-dir DIR`. The case's flags, tags, notes and finding decisions are kept.

## Install

Download the app and the CLI from this release. Install both from the same release: they refuse to talk to each other across versions, so the CLI from `v0.0.1-Alpha-02` will not work with this app.

The builds are not code-signed or notarized, so your system will warn you. `SHA256SUMS-macos-arm64.txt` lets you check each download first.

### macOS (Apple silicon)

1. Unzip `Sparrow-0.0.1-Alpha-03-macos-arm64.zip` and move `Sparrow.app` to Applications. If macOS blocks it the first time you open it, go to **System Settings > Privacy & Security** and choose **Open Anyway**. If it says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Sparrow.app`.
2. Run `tar -xzf sparrow-cli-0.0.1-Alpha-03-macos-arm64.tar.gz` and put `sparrow` in a folder on your `PATH`.

To check a download, run `shasum -a 256 -c SHA256SUMS-macos-arm64.txt` in the download folder.

### Windows, Linux and Intel Macs

No build is attached yet. Build from source with `scripts/release.sh`; see [Developer notes](https://github.com/darkoperator/Sparrow/blob/v0.0.1-Alpha-03/docs/DEVELOPING.md). The Windows installer on `v0.0.1-Alpha` still works, but it does not have these changes.

## Try it

Without any real evidence, Sparrow can generate a synthetic case:

```
sparrow synth --scenario bec-aitm --collector hawk4 --out tree
sparrow ingest tree --case case.duckdb
sparrow capabilities --case case.duckdb
sparrow finding list --case case.duckdb
```

Then open `case.duckdb` in the app. To use your own evidence, point `sparrow ingest` at a collector folder, or build a new case from a folder in the app.

GeoIP is optional. Without MaxMind GeoLite2 City and ASN files there is no geolocation, and rules that need it report `not_applicable`. The CLI takes them with `--geoip-dir DIR`; the app reads the folder chosen in its import dialog, or `~/geoip`.

## Known limits

- There is no automatic update. Each new build is a manual install of both the app and the CLI.
- Case files from this build may not open in later alpha builds, so keep your original evidence and expect to re-ingest.
- Only one process can write to a case file at a time.
- MailItemsAccessed exports are still read whole, so a very large one needs memory to match.
- In Events, a column the backend cannot filter or sort, such as Target, still cannot be. Use the raw-text search.
- The Access CSV has no app name column; its `app` column holds the application id or client text.
