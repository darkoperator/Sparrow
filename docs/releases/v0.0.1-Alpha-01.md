# Sparrow v0.0.1-Alpha-01

Second test build, for a small group. Expect rough edges, and check anything that matters against the original evidence before relying on it.

Sparrow turns Microsoft 365 evidence for a business-email-compromise investigation into one queryable DuckDB case file. It reads Hawk 3.x/4.x, Microsoft-Extractor-Suite (Invictus) and portal exports, then gives you a CLI and a desktop review app to work the case. It does not collect evidence itself. Use it only on collector output you are authorized to examine.

## What's new

- **Sort and filter the tables.** Click a column header to sort. Right-click it to filter by the column's values, with counts. Events and Tables filter on the backend; the other tables filter the rows they have loaded.
- **Date pickers on date columns.** Right-click a date column's header for From and To pickers, in UTC. In Events, Tables, SQL results and a finding's evidence, a right-click on a date cell offers the same.
- **App column in Access.** Each table now shows the app. Not every item has a name: the column falls back to the application id or the client the record names (`Client=OWA;...`), or `—` when the record names none. See [Access report](https://github.com/darkoperator/Sparrow/blob/v0.0.1-Alpha-01/docs/REFERENCE.md#access-report).
- **Right-click menus no longer get cut off** by the pane beside the table.
- **Rule guidance reads as normal text**, wrapped to its box.

## Install

Download the app and the CLI from this release. Install both from the same release: they refuse to talk to each other across versions, so the CLI from `v0.0.1-Alpha` will not work with this app.

The builds are not code-signed or notarized, so your system will warn you. `SHA256SUMS-macos-arm64.txt` lets you check each download first.

### macOS (Apple silicon)

1. Unzip `Sparrow-0.0.1-Alpha-01-macos-arm64.zip` and move `Sparrow.app` to Applications. If macOS blocks it the first time you open it, go to **System Settings > Privacy & Security** and choose **Open Anyway**. If it says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Sparrow.app`.
2. Run `tar -xzf sparrow-cli-0.0.1-Alpha-01-macos-arm64.tar.gz` and put `sparrow` in a folder on your `PATH`.

To check a download, run `shasum -a 256 -c SHA256SUMS-macos-arm64.txt` in the download folder.

### Windows, Linux and Intel Macs

No build is attached yet. Build from source with `scripts/release.sh`; see [Developer notes](https://github.com/darkoperator/Sparrow/blob/v0.0.1-Alpha-01/docs/DEVELOPING.md). The Windows installer on `v0.0.1-Alpha` still works, but it does not have these changes.

## Try it

Without any real evidence, Sparrow can generate a synthetic case:

```
sparrow synth --scenario bec-aitm --collector hawk4 --out tree
sparrow ingest tree --case case.duckdb
sparrow capabilities --case case.duckdb
sparrow finding list --case case.duckdb
```

Then open `case.duckdb` in the app. To use your own evidence, point `sparrow ingest` at a collector folder, or build a new case from a folder in the app.

GeoIP is optional. Without MaxMind GeoLite2 City and ASN files, passed with `--geoip-dir DIR`, there is no geolocation, and rules that need it report `not_applicable`.

## Known limits

- There is no automatic update. Each new build is a manual install of both the app and the CLI.
- Case files from this build may not open in later alpha builds, so keep your original evidence and expect to re-ingest.
- Only one process can write to a case file at a time.
- In Events, a column the backend cannot filter or sort, such as Target, still cannot be. Use the raw-text search.
- The Access CSV has no app name column; its `app` column holds the application id or client text.
