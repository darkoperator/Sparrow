# Sparrow v0.0.1-Alpha-05

Sixth test build, for a small group. Expect rough edges, and check anything that matters against the original evidence before relying on it.

Sparrow turns Microsoft 365 evidence for a business-email-compromise investigation into one queryable DuckDB case file. It reads Hawk 3.x/4.x, Microsoft-Extractor-Suite (Invictus) and portal exports, then gives you a CLI and a desktop review app to work the case. It does not collect evidence itself. Use it only on collector output you are authorized to examine.

## What's new

- **Five new detection rules** (39 in total; all `experimental`, see `docs/RULES.md`):
  - **SPW-MAIL-008** Mail deleted by a delegate from a hosting network, or with a finance subject.
  - **SPW-ID-011** A burst of refresh-token replays after revocation (sign-in error 50173) from networks the user never signed in from successfully.
  - **SPW-ID-012** One sign-in session used from many networks on one day.
  - **SPW-MAIL-009** Inbound mail from a look-alike of the tenant's domain or of an earlier correspondent (one edit, or `rn`/`vv`/`0`/`1`/`cl` swaps). This rule has no attack stage.
  - **SPW-ID-013** A self-service password reset from a country the user had not signed in from before the reset.
- **Graph sign-in JSON exports are read.** A JSON array of Graph `signIn` objects (interactive or non-interactive) is now recognised as sign-ins instead of being skipped.
- **Chained client IPs.** A client IP recorded as a chain (`a, b, c`) now uses its first address, so it gets GeoIP and ASN data.
- **More hosting networks.** Six ASNs were added to the hosting list (AS212238, AS62240, AS136787, AS141039, AS147049, AS39486).
- **Query error hints.** `sparrow query` and the app suggest the workaround when a query fails on a timezone function this build lacks (cast to `TIMESTAMP`) or on a reserved word used as a name (quote it or alias it with `AS`).
- **`sparrow ioc add --json`** now prints the review state it stored.
- **Collection manifests.** Microsoft-Extractor-Suite collection manifests are stored at ingest. Coverage uses the collector's intervals, lists collection gaps with the command to re-run, and the summary, ingest output, coverage, report and app show a banner when a collection is incomplete.
- **Cases from an earlier build:** run `sparrow profile --case case.duckdb` (with `--geoip-dir` if you use GeoIP) to apply the new hosting ASNs and chained-IP handling, then `sparrow detect --case case.duckdb` for the new rules. Graph sign-in JSON files and collection manifests are read only at ingest, so re-ingest to pick those up.

## Install

Download the app and the CLI from this release. Install both from the same release: they refuse to talk to each other across versions, so the CLI from `v0.0.1-Alpha-04` will not work with this app.

The builds are not code-signed or notarized, so your system will warn you. `SHA256SUMS-macos-arm64.txt` lets you check each download first.

### macOS (Apple silicon)

1. Unzip `Sparrow-0.0.1-Alpha-05-macos-arm64.zip` and move `Sparrow.app` to Applications. If macOS blocks it the first time you open it, go to **System Settings > Privacy & Security** and choose **Open Anyway**. If it says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Sparrow.app`.
2. Run `tar -xzf sparrow-cli-0.0.1-Alpha-05-macos-arm64.tar.gz` and put `sparrow` in a folder on your `PATH`.

To check a download, run `shasum -a 256 -c SHA256SUMS-macos-arm64.txt` in the download folder.

### Windows, Linux and Intel Macs

No build is attached yet. Build from source with `scripts/release.sh`; see [Developer notes](https://github.com/darkoperator/Sparrow/blob/v0.0.1-Alpha-05/docs/DEVELOPING.md). The Windows installer on `v0.0.1-Alpha` still works, but it does not have these changes.

## Try it

Without any real evidence, Sparrow can generate a synthetic case:

```
sparrow synth --scenario bec-aitm --collector hawk4 --out tree
sparrow ingest tree --case case.duckdb
sparrow capabilities --case case.duckdb
sparrow finding list --case case.duckdb
```

Then open `case.duckdb` in the app. To use your own evidence, point `sparrow ingest` at a collector folder, or build a new case from a folder in the app.

GeoIP is optional. Without MaxMind GeoLite2 City and ASN files there is no geolocation, and rules that need it report `not_applicable`. The CLI takes them with `--geoip-dir DIR`; the app reads the folder chosen in its import dialog, or `~/geoip`.

## Known limits

- There is no automatic update. Each new build is a manual install of both the app and the CLI.
- Case files from this build may not open in later alpha builds, so keep your original evidence and expect to re-ingest.
- Only one process can write to a case file at a time.
- MailItemsAccessed exports are still read whole, so a very large one needs memory to match.
- In Events, a column the backend cannot filter or sort, such as Target, still cannot be. Use the raw-text search.
- The Access CSV has no app name column; its `app` column holds the application id or client text.
